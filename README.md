# Şegra Pure Life

Doğal gıda takviyeleri, **Balen** arı/hijyenik ürünleri ve **Tiens** sağlıklı yaşam
ürünlerinin tanıtım web sitesi. Statik (HTML/CSS/JS), tek sayfa, tamamen responsive.

## 🌿 Özellikler
- Doğal/sağlık temalı modern tasarım (yeşil + altın palet)
- Sticky menü, hero, Markalar, Ürünler, Neden Biz, Hakkımızda, İletişim bölümleri
- Mobil uyumlu (hamburger menü), kaydırma animasyonları
- Trendyol & Hepsiburada mağaza linkleri
